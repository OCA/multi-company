Warns the user when they switch the active company (top-right company
selector) to a company that has no dedicated outgoing mail server
configured.

This module depends on ``mail_multicompany`` which adds a ``company_id``
field on ``ir.mail_server``. When the user switches companies, a check is
performed and a sticky warning notification is shown if no server is
assigned to the newly active company.

Configuration
=============

No special configuration is needed. Install the module and ensure your
outgoing mail servers have a company assigned via
*Settings → Technical → Outgoing Mail Servers*.

By default, a global/shared mail server (``company_id`` = False) does
**not** count as "configured" for a specific company. If a shared
fallback server should be treated as valid for every company, you can
customize the domain in ``models/res_company.py``.

Usage
=====

1. Switch to a different company using the top-right company selector.
2. If the newly active company has no outgoing mail server explicitly
   assigned to it, a sticky warning notification will appear:
   *"<Company Name> has no outgoing email server configured. Emails sent
   from this company may not be delivered."*
3. The notification only appears once per switch, not on every page load.
