1. Switch to a different company using the top-right company selector.
2. If the newly active company has no outgoing mail server explicitly
   assigned to it, a sticky warning notification will appear:
   *"\<Company Name\> has no outgoing mail server of its own. Its emails
   will be sent through another server and may be rejected or marked as
   spam."*
3. The notification only appears once per switch, not on every page load.
