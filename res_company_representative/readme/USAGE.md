To manage representative roles:
1. Activate developer mode.
2. Open **Settings**.
3. Open **Users & Companies**.
4. Select **Representative Roles** in the **Representative Settings**.
5. Create, edit or reorder the available representative roles.

Representatives are managed directly on the company form.

To assign representatives:
1. Open a company.
2. Open the **Representatives and Roles** tab.
3. Add a partner as a representative.
4. Select the appropriate representative role.
5. Use the sequence handle to change the display order.

Each partner can only be assigned once as a representative to the same
company.
