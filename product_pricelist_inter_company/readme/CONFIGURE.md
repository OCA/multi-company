1. Enable **Multi-Companies** in Settings.
2. Enable **Pricelists** in Sales (or Purchase) Settings.
3. Open the vendor company's pricelist (*Sales > Configuration > Pricelists* or *Purchase > Configuration > Pricelists*).
4. Set **Purchasing Companies** to the companies that buy from this vendor.
5. Add product rules to the pricelist as usual — supplierinfo records are created automatically.
